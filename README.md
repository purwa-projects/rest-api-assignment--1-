# Exploring and Implementing REST APIs

This project is a simple React REST API demonstration.

## What it does
- Sends a GET request to JSONPlaceholder.
- Handles the HTTP response.
- Converts the response to JSON.
- Displays API data visually.
- Shows loading and error states.
- Includes a short REST API report/summary.

## Run
npm install
npm run dev

## API
https://jsonplaceholder.typicode.com/posts

## Assignment coverage
REST concepts, GET requests, JSON responses, API integration, visual presentation, benefits and industry use of APIs.
